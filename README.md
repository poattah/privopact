# Privopact

Free, open-source privacy tools for web, mobile and connected TV that enforce your privacy rights automatically.

Website: [privopact.com](https://privopact.com)

## Tools

| Tool | Platform | Status |
| --- | --- | --- |
| [GPC for Chrome](gpc-for-chrome) | Chrome, Edge, Brave | Available |
| Mobile app | iOS, Android | On the roadmap |
| Connected TV | Smart TVs, streaming devices | On the roadmap |

### GPC for Chrome

Sends the [Global Privacy Control](https://globalprivacycontrol.org/) signal to every website you visit and shows which sites say they honor it. Everything runs locally: no accounts, no analytics and no requests to Privopact servers. See [gpc-for-chrome/README.md](gpc-for-chrome/README.md).

## Principles

Every Privopact tool follows the same rules:

- **Open source.** All code is public under the MIT license.
- **Local-first.** Data is processed on your device.
- **Least privilege.** Each tool asks only for the permissions it needs.
- **No remote code.** Everything that runs ships in the installed package.
- **Open standards.** Built on recognized signals like Global Privacy Control.
